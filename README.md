# 线稿拓扑修复与路径提取工作台

在浏览器里对一组二维直线段做拓扑修复与路径提取：查出断口、交叉、重叠和分叉，
修复后得到可继续加工的连续路径。**只处理几何线稿，不做图片识别。**

纯 Python 标准库 + 原生 HTML/CSS/JavaScript，无第三方包、无 CDN、无外部接口。

## 快速开始

```bash
python3 server.py                 # 默认 http://127.0.0.1:8080/
python3 server.py --host 0.0.0.0 --port 8000
```

打开浏览器访问 `http://127.0.0.1:8080/`。停止按 `Ctrl+C`。

也可以直接用浏览器打开 `static/index.html`（此时“载入样例”因浏览器对
`file://` 的限制需要手动导入 `fixtures/cases.json` 中对应 draft；建议走 server）。

## 操作指引

| 操作 | 方式 |
|---|---|
| 编辑线段 | 左侧表格直接改 ID / a.x a.y / b.x b.y；✕ 删除；勾选框启用/禁用 |
| 新增线段 | 「＋ 新增线段」，默认从原点向右 10 个单位 |
| 样例 | 顶栏下拉选择后点「载入样例」（来自 `fixtures/cases.json`） |
| 执行修复 | 「执行修复」按钮（修复不消耗撤销） |
| 叠加快照 | 原图（灰实线/虚线）与修复图（蓝线、节点符号）同时显示，可用复选框切换 |
| 平移 | 鼠标拖拽（或按住 Shift 拖）；适配视图、＋/－ 按钮或滚轮缩放 |
| 点选联动 | 点画布上的原始线段 / 修复节点 / 边，表格行与路径项双向高亮；点空白取消 |
| 定位问题 | 右侧问题列表：诊断（零长度/退化）、共线重叠边、度1 端点、度>2 分叉 |
| 导出 | 「导出 topology.json」（仅当前修复结果**有效**时可用）；「导出草稿」随时可用 |
| 导入 | 「导入草稿」选 JSON 文件；**整体校验，失败不改动当前草稿**，错误定位到字段 |
| 撤销/重做 | 保留 50 次完整编辑（规格要求 ≥30）；坐标、增删、启停、吸附距离、成功导入/样例替换都算一次 |
| 自动保存 | 草稿写入 `localStorage`；刷新只恢复草稿，不会假装已重新校验/修复 |

坐标采用 **x 向右、y 向上**（画布做了 y 翻转，导出坐标与世界坐标一致，不随屏幕反转）。

## 修复管线（顺序固定，不可调换）

1. **原始零长度**（a≡b）先诊断并排除，其坐标不进入吸附端点集合，不能当传递吸附的桥。
2. **端点吸附**：对其余启用线段的所有端点，欧氏距离 `≤ snapDistance + 1e-9` 即相连，
   取传递闭包；每组统一移到组内按 `(x,y)` 字典序最小的**原端点**——不取平均，
   也不边遍历边改判断坐标。
3. **吸附后退化**（两端被吸到同一点）诊断并从交点阶段排除。
4. **求交与切分**：在吸附后的线段上收集全部端点与交点（端点落在线段内部的 T 接、
   十字交叉、共线重叠区间的端点），按交点把每条线段切成小边。
5. **同点归一**：收集所有端点与交点，对欧氏距离 `≤ 1e-9` 的点取传递闭包，
   每组归一到组内字典序最小的点。**新增交点不再按 snapDistance 吸附**，阈值固定 1e-9。
6. **重合去重**：完全重合的小边只保留一份，`sources` 记录覆盖它的全部原始线段 ID。
7. **构图与路径提取**：把结果视为无向图。从度 ≠ 2 的节点出发，只穿过度 2 节点，
   到下一个非 2 度节点停止；剩下纯 2 度连通分量提取为闭环。每条边恰好属于一条路径。

## 路径归一规则与几何含义

- 节点按 `(x,y)` 字典序从 0 开始编号；边的端点按编号排序（`from < to`），再按编号对排序。
- **开链**从两端编号较小的一端开始；**闭环**旋转到环中编号最小的节点起步，
  按笛卡尔坐标（y 向上）**逆时针**排列，`nodes` 末尾重复起点；面积为正的包围面积，
  不同闭环分别计算，不对嵌套环做孔洞相减。
- 凡首尾节点相同即 `closed=true`——包括从分叉点绕行一圈回到同一分叉点的情况
  （带支线的环不会被误算成开链）。开链 `area=null`，不显示虚构面积。
- 路径按节点编号序列字典序排序；长度/面积用内部完整精度计算，输出保留最多六位小数。
- `sources` 去重并按 Unicode 码点排序。页面展示与 `topology.json` 导出来自同一次 `repair()`。

## 验证样例（全部由引擎实时计算，非写死）

| 样例 | 阈值 | 预期 |
|---|---|---|
| 十字交叉 | 0 | 5 节点 / 4 边 / 4 开链 |
| 共线重叠 | 0 | 4 节点 / 3 边；中间边 `sources=[long,shifted]` |
| 方形闭环 | 0 | 4 节点 / 4 边 / 1 闭环，面积 100 |
| 近闭合断口 | 0 | 1 开链 |
| 近闭合断口 | 0.2 | 1 闭环，面积 100 |
| 传递吸附与退化边 | 0.2 | 三端点闭包到 (0,0)；`collapse` 报 COLLAPSED_AFTER_SNAP |
| 端点落在线段内部 | 0 | T 接 3 条开链；禁用段不参与；零长度点报 ZERO_LENGTH_INPUT |
| 闭环带一条支线 | 0 | 1 环（面积 100）+ 1 开链，环回到分叉点本身 |
| 零长度点不参与吸附 | 0.2 | 零长度点不桥接，保持 2 连通分量 |

```bash
./run_tests.sh

node tests/run_tests.js

```

测试覆盖：交叉切分、共线重叠去重及来源、传递吸附（不取平均）、分叉处截断、
闭环方向与面积、路径边覆盖不变量、稳定排序、零长度不桥接、近闭合阈值边界、
新增交点不二次吸附、大坐标整数谓词、草稿校验（布尔代数字等逐条拒绝）、
**编辑后旧结果失效且禁止导出**、**导入失败不污染草稿、不入撤销栈**、
撤销/重做（含 50 次上限）以及草稿导出往返保留 ID/顺序/启用状态。

## 草稿与导出格式

遵循 `fixtures/format.md`：

- 顶层仅允许 `version(=1)`、`name(1～80)`、`snapDistance(0～10，最多三位小数)`、`segments(≤200)`。
- 线段恰有 `id(1～40 字符，唯一，区分大小写)`、`enabled(布尔)`、`a`、`b`；
  坐标必须是有限数字（**布尔、数字字符串、null 一律拒绝**）、|x/y| ≤ 10000、最多三位小数。
- 未知字段、缺失字段、重复 ID、JSON 语法错误都会整体拒绝，错误信息定位到
  `$.segments[i].a.x` 这样的字段路径。允许空线稿与原始零长度线段（诊断展示，不参与拓扑）。
- 禁用线段留在草稿里，但不参与任何计算；再次启用即恢复。
